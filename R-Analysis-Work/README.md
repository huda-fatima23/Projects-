# R Analysis Work

This folder contains statistical analysis projects completed using R as part of my graduate coursework in Health Data Science.

## Analyses Included

### Chi-Square Analysis
- Examined associations between categorical variables
- Performed Chi-square tests
- Evaluated expected frequencies and standardized residuals
- Interpreted statistical significance and associations

### ANOVA Analysis
- Conducted one-way and two-way ANOVA
- Evaluated main and interaction effects
- Checked normality and homogeneity of variance assumptions
- Performed post-hoc comparisons
- Interpreted statistical results

### Regression Analysis
- Conducted simple and multiple linear regression
- Evaluated model assumptions using residual diagnostics
- Used Breusch-Pagan and Durbin-Watson tests
- Interpreted regression coefficients, p-values, confidence intervals, and R-squared
- Compared regression models
