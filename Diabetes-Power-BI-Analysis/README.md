# Diabetes Analysis Dashboard – Power BI

## Project Overview
This project uses Power BI to analyze a diabetes dataset and explore relationships between patient characteristics and diabetes outcomes.

## Tools
- Power BI
- Power Query
- DAX

## Data Preparation
- Removed duplicate records
- Replaced clinically unrealistic zero values with null values for Glucose, Blood Pressure, Skin Thickness, Insulin, and BMI
- Created grouped variables for analysis
- Prepared the dataset using Power Query

## Dashboard Features
- KPI cards
- Bar charts
- Donut chart
- Scatter plot
- Combination chart
- Interactive slicers
- BMI and age group analysis

## Analysis
The dashboard explores:
- Diabetes outcomes across patient groups
- Relationship between BMI and glucose
- Diabetes distribution by age group
- Pregnancy patterns
- Key patient health indicators

## Skills Demonstrated
- Data cleaning with Power Query
- Data modeling
- DAX calculations
- Interactive dashboard development
